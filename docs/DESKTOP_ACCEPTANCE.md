## 在线底图根因和修复

上次独立验收启动器对 renderer 的所有 HTTP(S) 请求执行 `cancel: true`，同时取消了产品原有 OpenFreeMap 样式。十秒后地图组件进入本地轨迹/位置占位退化状态。Node SDK 的资料、车辆和行程请求不经过这条 Electron renderer 规则，不能据此认定行程接口失败。

公开请求验证显示：`https://tiles.openfreemap.org/styles/positron`、TileJSON、全球 z0 测试瓦片、精灵图和字体均返回 HTTP 200；正常 TLS 校验下成功，CORS 为 `*`。样式依赖资源都来自同一既有域名，产品 CSP 已允许该域名；本轮没有证据指向证书或 CSP 错误。

修复提交 `aa84276` 把可复现的独立启动器放入 `scripts/sdk-desktop-acceptance.cjs`，仅允许原有 `https://tiles.openfreemap.org` origin；HTTP、其他端口、相似域名、带用户名密码的 URL 和其他外部 origin 仍被取消。产品入口、认证默认、CSP、TLS 和地图供应方不变。当前验收目录中的短启动脚本调用此版本化入口。

脱敏网络记录只保留资源类别、完成/失败计数、HTTP 状态或固定网络错误码，不记录完整 URL、瓦片坐标、查询参数或响应体。

参考：[OpenFreeMap 官方集成说明](https://openfreemap.org/quick_start/)、[MapLibre 官方安装及 CSP 说明](https://maplibre.org/maplibre-gl-js/docs/)。
