# 骑迹 v0.1.0

首个公开测试版，面向 macOS Apple Silicon。

## 主要能力

- 按年、月和骑行日浏览完整汇总，并区分完整月度统计与最多 20 条可选择明细。
- 轨迹地图、逐点速度着色、速度曲线和 0.5× 至 4× 回放。
- 用轨迹采样校验历史记录中固定为 25 km/h 的摘要极速。
- 展示能耗、电量消耗、平均能耗、骑行日累计和同月行程对比。
- 导出单次 GPX/CSV/JSON、月度清单和年度摘要。
- 多车辆、共享车辆、双电池、按需车辆位置和只读状态监看。

## 安装前须知

- 这是 ad-hoc 签名、未经过 Apple 公证的 prerelease。Gatekeeper 可能阻止打开；它不是稳定正式版。
- 安装包不包含 uv 或 ninecli。请先运行 `brew install uv`；应用只请求 `ninecli==0.1.7` 并校验其 macOS arm64 二进制哈希。
- ninecli 与九号云端接口均不是本项目提供的官方 API，可能变化或停止工作。
- 本项目不是九号官方产品，也未获得九号品牌或商业背书。
- 源码当前为 `UNLICENSED`，公开可见不代表获得复制、修改或再分发许可。

下载后可使用 Release 附带的 `SHA256SUMS.txt` 校验 DMG 和 ZIP。
