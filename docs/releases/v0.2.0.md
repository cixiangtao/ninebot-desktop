# 韭号出行 v0.2.0

新增 Windows x64 测试版，并保留 macOS Apple Silicon 下载。

## 新增能力

- Windows x64 提供 NSIS 安装程序与 ZIP 便携包。
- Windows 运行时锁定并校验 `ninecli==0.1.7` wheel 内 `ninecli.exe` 的 SHA-256。
- 从用户 `PATH`、`%USERPROFILE%\.local\bin`、`%USERPROFILE%\.cargo\bin` 和 WindowsApps 定位 `uvx.exe`。
- Windows 包在真实 Windows runner 上验证 PE x64、版本、ASAR、Electron Fuses、未捆绑 ninecli、ZIP 可读性和未签名状态。
- NSIS 安装程序会静默安装到临时目录，从安装结果启动完整运行时冒烟，并确认卸载程序存在。
- macOS 与 Windows 构建都成功后，由同一个 GitHub Actions 发布任务生成统一的 `SHA256SUMS.txt`。

## 安装前须知

- Windows 需要 Windows 10 或更高版本的 x64 系统，并先运行 `winget install --id=astral-sh.uv -e`。
- Windows 包尚未进行 Authenticode 签名，Microsoft Defender SmartScreen 可能显示警告；它仍属于 prerelease。
- macOS 包仍是 ad-hoc 签名且未经过 Apple 公证，Gatekeeper 可能阻止打开。
- 安装包不包含 uv 或 ninecli。应用只请求固定的 `ninecli==0.1.7` 并校验对应平台二进制哈希。
- ninecli 与九号云端接口均不是本项目提供的官方 API，可能变化或停止工作。
- 本项目不是九号官方产品，也未获得九号品牌或商业背书。
- 源码当前为 `UNLICENSED`，公开可见不代表获得复制、修改或再分发许可。
